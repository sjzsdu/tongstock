# 工作约束

1. 对方法名先搜索，再抓取候选网页正文；搜索结果摘要本身不能作为完整来源。
2. 区分作者原始发布、媒体报道、论坛或自媒体转述。无法确认原作者时不得标 primary。
3. 每一条入场、退出、仓位、例外、失效和适用市场规则都必须关联短引用；AI 补充解释必须标 ai_inference。
4. 同一语义字段出现不同时间、阈值或条件时，输出不同 claim 和不同 variant。
5. 不得声称方法有效。验证只能由 TongStock 的真实数据验证工厂完成。
