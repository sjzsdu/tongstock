## 行情

数据来自**通达信（TDX）官方行情服务器**，默认端口 `7709`。客户端直连上游，没有中间服务商。

覆盖范围是 A 股三个交易所：上海（`sh`）、深圳（`sz`）、北京（`bj`）。

| 类别 | 包含 |
| --- | --- |
| 行情 | 五档买卖盘、昨收、内外盘、成交量/额 |
| K 线 | 1/5/15/30/60 分钟与日、周、月、季、年 |
| 分时 | 当日与历史分时 |
| 分笔 | 当日与历史逐笔成交 |
| 除权除息 | 分红、送股、配股、股本变动 |
| 财务 | 总股本、流通股、净资产、净利润等（**单位千元**） |
| 公司信息 | F10：最新提示、公司概况、财务分析、股东研究等 |
| 板块 | 行业、概念、地域、风格 |
| 集合竞价 | 匹配量、未匹配量 |
| 指数 | 指数 K 线，含上涨/下跌家数 |

## 资讯

新闻来自九个公开来源，代码在 `pkg/newsfeed/sources/`：

| 源 | 说明 |
| --- | --- |
| 财联社 | 快讯 |
| 东方财富 | 新闻与研报 |
| 巨潮资讯 | 公告 |
| 证券时报 | 财经新闻 |
| 第一财经 | 财经新闻 |
| 新浪财经 | 财经新闻 |
| 腾讯财经 | 财经新闻 |
| 雪球 | 讨论与资讯 |
| 21 世纪经济报道 | 财经新闻 |

聚合后按个股做实体识别，再挂到代码上；同时提供热点事件与情绪相关的端点（见[资讯](/docs/api/news/)）。

## 板块文件的四个分类

| 文件 | 内容 |
| --- | --- |
| `block.dat` | 综合板块 |
| `block_zs.dat` | 指数板块（主要指数成分股） |
| `block_fg.dat` | 行业板块 |
| `block_gn.dat` | 概念板块 |

## 边界与免责

- 行情数据**可能有延迟**，不构成交易依据。
- 本项目**仅供学习研究使用**，请遵守通达信的服务条款，不要用于商业用途。
- 新闻内容版权归各来源所有，本站只做聚合与索引。
- 系统所有计算都基于你本地实际拿到的数据；数据缺失时会明确报错或拒绝推荐，而不是用模型想象力补全。
