## 明确不做的事

| 不做 | 原因 |
| --- | --- |
| 不替你下单 | 没有券商接口，产出的是判断与执行约束 |
| 不承诺收益 | 没有任何收益、胜率、准确率的对外承诺；验证只给证据等级 |
| 不用云端账号 | 不需要注册，数据落本地 SQLite |
| 不在数据缺失时编造 | 缺就报错或拒绝推荐，不做“看起来合理”的补全 |
| 不把推断包装成事实 | 血缘缺失标 `inferred`，无法执行就说无法执行 |

## 数据的不确定性

- **行情可能有延迟**：数据来自通达信公开行情服务器，实时性与官方交易终端不能等同。
- **历史数据可能残缺**：历史分时、历史分笔的可得窗口受上游限制；跨年比较前必须看除权除息数据。
- **新闻是聚合结果**：九个公开源，各自有立场与延迟；情绪打分是对文本的聚合，不是对价格的预测。
- **财务数值单位是千元**：二次计算前请确认量纲。
- **点时数据可能缺失**：历史验证缺某时点的市值序列时会 fail-closed，而不是回填。

## 使用边界

- 本项目**仅供学习研究使用**，请遵守通达信的服务条款，不要用于商业用途。
- 行情数据可能有延迟，**不建议用于实盘交易**。
- 系统输出的任何“候选”“建议”“动作”都是基于历史数据的统计结论，不构成投资建议。
- 投资决策及其后果由使用者自行承担。

## 已知的技术限制

| 限制 | 说明 |
| --- | --- |
| 只支持 A 股三所 | 上海、深圳、北京；没有港美股与期货 |
| 只有 SQLite | 官方仅支持 `sqlite3`，没有 Postgres/MySQL 适配 |
| 单机为主 | 设计是自托管单实例，不是多租户服务 |
| 依赖相邻仓库 | `go.mod` 通过 `replace` 引用 `picoclaw`，源码构建需准备该目录 |
| 网络受限环境 | 无网时只能用 `cache_only` + 已同步数据 |
