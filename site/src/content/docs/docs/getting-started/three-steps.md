---
title: 三步上手
description: 从首页输入研究问题，到今日决策，再到持仓卖出队列——主流程只有三步。
---

主流程刻意做得很短。以下三步都在 Web UI 里完成（`./tongstock serve` 后打开 `http://127.0.0.1:8106/`）。

## 第一步：在首页输入问题

首页（今日决策，路径 `/`）接受三种输入：

- 股票代码，例如 `000063`
- 已知方法名称
- 自然语言研究问题，例如“研究 000063 最近上涨前的共同特征”

输入会被交给 AI 层转成结构化候选，再由确定性引擎编译与验证。

## 第二步：看“今日决策”

首页下半部分是今天的候选。每个候选同时给出：

| 字段 | 含义 |
| --- | --- |
| 真实数据日期 | 结论基于哪一天的真实数据，而不是“今天”这个模糊说法 |
| 方法证据 | 这条规则来自哪个方法、证据等级如何 |
| 买入窗口 | 允许进场的日期区间 |
| 仓位上限 | 单票能占多大比例 |
| 退出计划 | 什么条件触发离场 |

**如果榜单是空的，那是结论本身**：当前没有方法通过门槛。页面上会给出被排除的原因分布，可以用“空榜原因”面板查看是数据不足、样本不够，还是没通过验证。

## 第三步：在“持仓卖出”看处置意见

路径 `/portfolio`，输出四类动作：

- `hold` —— 继续持有
- `watch` —— 观察，条件临近但不触发
- `reduce` —— 减仓
- `exit` —— 退出

两条如实标注的规则值得注意：

1. **旧持仓没有原始方法血缘时，会明确标为 `inferred`**，而不是伪装成“当初就是用这个方法选的”。
2. **停牌或 T+1 限制下不会假装已经卖出**，执行约束会单独列出来。

## 相关页面

决策依赖的方法与证据在另外两处：

- `/methods`（我的选股方法）—— 一句话规则、历史验证胜率口径、证据等级，可按方法筛选今日股票。
- `/methods/advanced`（高级研究与管理）—— 自动研究、因子研究、方法比较、反馈与前向健康管理。范式库与监控也归在这个入口下（`/paradigms`、`/monitoring` 路由仍保留）。

## 不想开浏览器

同样的流程有 CLI 与 HTTP 入口：

```bash
# 生成每日买入候选（省略快照 id 时使用最新 ready 快照）
./tongstock select run

# 查看一次不可变选股运行
./tongstock select list

# 基于真实持仓与冻结快照判断何时卖
./tongstock position decide

# 幂等跑完一整天的选股 + 持仓判断 + 提醒闭环
./tongstock automation run
```

细节见[决策流水线](/docs/usage/decision-pipeline/)。
